# Эмулятор UNIX-подобной командной строки

## 1. Общее описание
Программа представляет собой эмулятор языка оболочки ОС, имитирующий работу в командной строке UNIX-подобной ОС. Приложение реализовано в форме консольного интерфейса (CLI), где приглашение к вводу формируется на основе данных операционной системы в формате `username@hostname:~$ `. Эмулятор разработан в соответствии с требованиями Варианта №18. Документация структурирована согласно общим требованиям к практическим работам.

## 2. Описание всех функций и настроек
Приложение поддерживает следующий набор возможностей:

**Конфигурация и запуск:**
* Параметры запуска (путь к VFS, стартовому скрипту и лог-файлу) могут передаваться как через аргументы командной строки, так и через конфигурационный файл формата XML.
* Значения из командной строки имеют приоритет над значениями из конфигурационного файла.

**Виртуальная файловая система (VFS):**
* Источником файловой системы выступает CSV-файл.
* Для хранения двоичных данных файлов применяется формат base64.
* Все операции модификации файлов (например, создание) осуществляются исключительно в оперативной памяти без изменения реальных файлов на диске.

**Логирование:**
* Все события вызова команд сохраняются в лог-файл формата JSON.
* Запись лога включает саму команду, дату и время события, а также сообщение о возникшей ошибке.

**Стартовый скрипт:**
* Поддерживается автоматическое последовательное выполнение команд из текстового файла.
* При выполнении имитируется диалог с пользователем (выводится ввод и вывод), а скрипт останавливается при возникновении первой ошибки.

**Поддерживаемые команды:**
* `ls` и `cd` — базовая навигация и просмотр содержимого директорий.
* `exit` — завершение работы эмулятора.
* `who` — вывод информации о текущем пользователе.
* `tail` — вывод последних строк указанного файла.
* `touch` — создание пустого файла (модификация происходит только в памяти VFS).

## 3. Описание команд для сборки проекта и запуска тестов
Проект написан на интерпретируемом языке Python, предварительная сборка не требуется.

**Запуск эмулятора с файлом конфигурации:**
```bash
python src/main.py --config config.xml
```

**Запуск с переопределением параметров командной строки:**
```bash
python src/main.py --config config.xml --vfs tests/vfs_minimal.csv --log custom_log.json
```

**Запуск тестов:**
Для проверки работы VFS (различная вложенность, минимальные файлы, обработка ошибок) подготовлены bash-скрипты. Для их запуска используйте команды:
```bash
chmod +x tests/*.sh
./tests/test_vfs_errors.sh
./tests/test_vfs_minimal.sh
./tests/test_vfs_flat.sh
./tests/test_vfs_deep.sh
```
