# Эмулятор командной оболочки ОС

## 1. Общее описание
Данный проект представляет собой эмулятор UNIX-подобной командной оболочки. Приложение реализовано на языке Python и работает в режиме интерфейса командной строки (CLI). Эмулятор поддерживает интерактивный ввод (REPL), формирует приглашение на основе реальных данных операционной системы и корректно обрабатывает аргументы, заключенные в кавычки. На текущем этапе реализован базовый парсер и команды-заглушки.

## 2. Описание функций и настроек
**Основные функции (модуль `src/main.py`):**
* `get_prompt() -> str`: Формирует строку приглашения к вводу в формате `username@hostname:~$`.
* `process_command(user_input: str) -> None`: Обрабатывает введенную строку, разделяя её на команду и аргументы с помощью модуля `shlex` (с поддержкой кавычек). Перехватывает ошибки незакрытых кавычек.
* `main() -> None`: Запускает бесконечный цикл обработки ввода пользователя (REPL), безопасно перехватывает системные прерывания (`Ctrl+C`, `Ctrl+D`).

**Поддерживаемые команды (заглушки первого этапа):**
* `ls [аргументы]` — выводит свое имя и переданные аргументы.
* `cd [аргументы]` — выводит свое имя и переданные аргументы.
* `exit` — корректно завершает работу эмулятора.

**Настройки:**
На текущем этапе дополнительные конфигурационные файлы не используются.
